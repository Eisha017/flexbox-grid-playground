# 📖 Overview

Modern websites rely on **Flexbox** and **CSS Grid** for building responsive layouts.

This project recreates the **same pricing section twice**:

- 🔹 Using **CSS Flexbox**
- 🔹 Using **CSS Grid**

Building both versions provides a practical understanding of how each layout system works, when to use it, and the differences between them.

# ⚖️ Flexbox vs CSS Grid

| Flexbox | CSS Grid |
|----------|-----------|
| One-dimensional layouts | Two-dimensional layouts |
| Best for rows or columns | Best for complete page layouts |
| Great for components | Great for dashboards and sections |
| Flexible alignment | Precise row and column control |
| `display: flex` | `display: grid` |
